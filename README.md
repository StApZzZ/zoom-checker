# Zoom Checker — автоматический учёт посещаемости занятий в Zoom

Сервис в реальном времени получает от Zoom события входа и выхода участников, сопоставляет
отображаемые имена со списком группы и сам формирует посещаемость. Преподаватель во время урока
видит, кто сейчас в Zoom, кто вышел, кто не подключался, сколько времени был каждый студент и
каких участников не удалось опознать. После урока — готовая ведомость в Excel.

<p align="center">Zoom → webhook → Zoom Checker → экран преподавателя (обновление ≈ 0,2 с)</p>

## Возможности

- **Живой экран занятия**: статусы 🟢 В Zoom / 🟡 Вышел / 🔴 Не подключался, время присутствия,
  опоздания, счётчики «В группе / Сейчас в Zoom / Были / Не подключались / Не идентифицированы».
- **Точное сопоставление по имени** (регистр, пробелы, «ё»/«е» не важны) — без «угадывания».
  Неопознанные участники — отдельным списком; одно нажатие переносит их время студенту, а
  «Запомнить это имя» решает вопрос и на следующих занятиях.
- **Честный подсчёт времени**: переподключения складываются, два устройства одновременно не
  задваиваются, комнаты для групповой работы учитываются, при окончании конференции все интервалы закрываются.
- **Надёжный приём событий Zoom**: проверка подписи, сохранение «как есть» до обработки,
  защита от повторов и событий не по порядку, журнал событий для разбора.
- **Ручные исправления** с историей: отметка «был/не был», комментарии, сопоставления.
- **Импорт списков** из Excel, CSV (в том числе Windows-1251) или простым копированием текста.
- **Выгрузка** занятия и сводки группы в Excel / CSV.
- **Вход**: локальные учётные записи, **Keycloak** (OpenID Connect) и **Active Directory / LDAP**,
  в любом сочетании; роли из групп.
- **Лёгкий**: один файл ~27 МБ, ~25 МБ памяти, встроенная база SQLite (или PostgreSQL),
  встроенный HTTPS от Let's Encrypt (для приёма событий Zoom нужно доменное имя; веб-интерфейс
  работает и по IP-адресу).

## Быстрый старт

Что понадобится: сервер Linux с systemd (или любой компьютер с Docker), открытые из интернета
порты 80 и 443 ([как открыть их у облачного провайдера](docs/admin-guide.md#откройте-порты-80-и-443-у-облачного-провайдера))
и **доменное имя**, указывающее на сервер: Zoom отправляет события только на https-адрес с доменным
именем. По IP-адресу откроется веб-интерфейс, но Zoom такой адрес не примет
([как перейти с IP на доменное имя](docs/admin-guide.md#перейти-с-ip-адреса-на-доменное-имя)).

**Сервер Linux с systemd.** Скачайте пакет установки последней версии со страницы
[Releases](https://github.com/StApZzZ/zoom-checker/releases/latest) прямо на сервер и запустите установщик:

```bash
curl -fLO https://github.com/StApZzZ/zoom-checker/releases/latest/download/zoom-checker-linux.tar.gz
mkdir zoom-checker && tar -xzf zoom-checker-linux.tar.gz -C zoom-checker && cd zoom-checker
sudo ./install.sh --public-url https://attendance.example.com
```

В пакете — бинарники для amd64 и arm64 (установщик сам выберет нужный), `install.sh`, systemd-юнит и
шаблон настроек `.env.example`. Пакет можно собрать и самому из исходного кода — по шагам в
[руководстве администратора](docs/admin-guide.md#как-получить-пакет-установки).

Установщик спросит Secret Token из Zoom (при вставке он не показывается на экране; если токена ещё
нет — нажмите Enter и добавьте его позже).

**Docker** (образ собирается из исходного кода):

```bash
git clone https://github.com/StApZzZ/zoom-checker.git
cd zoom-checker/deploy
cp .env.example .env && chmod 600 .env   # в файле будут пароли — читать его может только владелец
nano .env                                # укажите PUBLIC_URL и ZOOM_WEBHOOK_SECRET_TOKEN
docker compose up -d --build
```

Подробнее — [deploy/README-docker.md](deploy/README-docker.md).

**Попробовать на своём компьютере** (без Zoom — с имитатором событий; нужны Go 1.26+ и Node.js 22):

```bash
make build
ZOOM_WEBHOOK_SECRET_TOKEN=demo ADMIN_PASSWORD=admin12345 ./bin/zoom-checker
# откройте http://localhost:8080 и войдите: admin / admin12345
```

1. **Группы → Новая группа**: введите любое название и вставьте этот список — по одному студенту в строке:

   ```text
   Иванов Иван
   Петрова Анна
   Сидоров Алексей
   Смирнова Мария
   Кузнецов Дмитрий
   Попова Екатерина
   Васильев Михаил
   Новикова Ольга
   Фёдоров Артём
   Морозова Дарья
   Волков Никита
   Соколова Алёна
   ```

2. **Занятия → Новое занятие**: эта группа, время — сейчас, номер конференции `123 456 7890`.
   Откройте занятие.
3. В другом терминале запустите «урок» за 3 минуты и смотрите, как меняется страница занятия:

   ```bash
   ./bin/zoom-checker simulate --meeting 1234567890 --secret demo --url http://localhost:8080/api/webhooks/zoom
   ```

Свой список имён для имитатора — `--names ФАЙЛ` (по одному имени в строке).

Дальше — подключить Zoom (5 минут в Zoom Marketplace): см. [руководство администратора, раздел 6](docs/admin-guide.md#6-подключение-zoom).

## Технологии

Go 1.27 (стандартная библиотека, SQLite без CGO / PostgreSQL, certmagic, go-oidc, go-ldap, excelize) ·
React 19 + TypeScript + Vite + Tailwind CSS 4 + shadcn/ui + TanStack Query · Server-Sent Events ·
Playwright. Почему так: один статический бинарник без зависимостей проще всего установить и
обслуживать, а Go даёт минимальное потребление памяти; веб-интерфейс встроен в бинарник.

## Разработка

```bash
make build        # фронтенд + бинарник → bin/zoom-checker
make test         # Go-тесты (с -race)
cd web && npm test    # тесты интерфейса
make e2e          # сквозные тесты в браузере (Playwright), включая все сценарии приёмки
make test-pg      # тесты хранилища на PostgreSQL в Docker
make release      # пакет установки: бинарники linux amd64/arm64 + install.sh → dist/
make package      # то же одним архивом → dist/zoom-checker-linux.tar.gz
make dev          # бэкенд :8080 + Vite :5173 с горячей перезагрузкой
```

Тестовый стенд Keycloak + OpenLDAP + Samba AD: [deploy/dev/auth-stand](deploy/dev/auth-stand/README.md).
